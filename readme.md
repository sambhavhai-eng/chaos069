# CHAOS MVP v2

A polished clickable frontend MVP for CHAOS — a random social game built around anonymous 1-to-1 matching and surprise challenges.

## Prototype features
- Landing page + START CHAOS
- Random-match simulation
- Chaos Event generator
- Anonymous chat
- NEXT flow
- XP + streak concept
- Mic/camera UI controls
- Report flow
- Responsive mobile layout

## To become a real product
Replace the simulated matching with WebRTC + signaling, add a matchmaking queue, persistent backend state, moderation/reporting tools, rate limits, and robust age-safety protections.
